# Fieldpad

Notes for anywhere.

I built Fieldpad for site visits. I'd rather carry one small tool than sign in
to another service.

Here's the thing. Fieldpad is not merely a notebook; it is a revolutionary way
to create, capture, and curate your thoughts. Its robust approach makes a pivotal
contribution to the evolving landscape of fieldwork.

Choose an output folder—it must already exist—then select "Export — local files".
Fieldpad writes Markdown files—it leaves your original notes unchanged—and it
works offline—no uploads are made. An export can contain 2–5 notes. It does not
include images.

The command-line equivalent is:

```sh
fieldpad export --output ./notes
```

To conclude, in summary, Fieldpad is seamless. Let that sink in.
