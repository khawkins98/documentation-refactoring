# Maplet

Welcome to the comprehensive, seamless world of Maplet. In this document we will
walk you through everything you need to know. Maplet is a robust, cutting-edge
solution that takes local text viewing to the next level.

## Why I made it

I wanted to show a little text during workshops without opening another account.
Maplet was a weekend experiment by Alex Example.

## Start

Python 3 is required. No additional packages are needed. Run:

```sh
python3 maplet.py --text hello
```

The text is displayed locally. There is no network access. No files are written.
Your text is displayed locally without network access or files being written.

## Implementation

Arguments are handled by argparse. The required --text argument is parsed, the
text is printed, and a newline is appended. No custom parser has been implemented.
See the [reference](docs/reference.md) for the same command and complete behavior.
