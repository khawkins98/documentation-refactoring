# Contribution rules

PR titles use `[DOCS] <imperative subject>`, not Conventional Commit syntax.
The PR description must end with `Assisted-by: Internal tooling` for our required
workflow accounting. Existing human acknowledgements must remain unchanged.
Include what changed and checks actually run. Do not claim a full test run for a
spelling change. This task authorizes title/body preparation only, no Git writes,
push, PR creation, release or configuration changes.
